# Merou Widget Studio (يعمل مجاناً على Render)

لوحة تحكم خاصة بك تعدّل منها بيانات **ويدجت بروفايل ديسكورد** في أي وقت من الهاتف، وتُرسل التغييرات إلى ديسكورد عبر واجهته الرسمية (Application Identity Profile API) بدون حاسوب وبدون أي حيلة غير مسموحة.

## لماذا ليس Rich Presence على Render؟
الـ Rich Presence يتصل بتطبيق ديسكورد **المثبّت على جهازك** عبر قناة محلية، فلا يمكن تشغيله على سيرفر. لذلك هذا المشروع يستخدم **الويدجت** الذي تُخزَّن بياناته عند ديسكورد، فتبقى ظاهرة في بروفايلك حتى لو كان الخادم نائماً.

> تنبيه صريح: قسم Widget في Developer Portal موثّق من ديسكورد للألعاب المسجّلة (Claimed)، وقد لا يظهر لكل الحسابات. لم أستطع تجربته على حسابك. إن لم يظهر لك **Games ← Widget** فاتبع نموذج الوصول/Game Claiming الذي يعرضه ديسكورد، وإلا فاستخدم مشروع RPC على الحاسوب.

## 1) إعداد التطبيق في Developer Portal
1. https://discord.com/developers/applications ← New Application (أو استخدم تطبيقك الحالي).
2. انسخ **Application ID**.
3. **Bot**: Reset Token وانسخه (DISCORD_BOT_TOKEN).
4. **OAuth2**: انسخ **Client Secret**، ثم في Redirects أضف:
   `https://اسم-خدمتك.onrender.com/callback`
5. من الشريط الجانبي: **Games ← Widget** وصمّم الويدجت (Widget Top / Widget Bottom / Add Widget Preview) ثم Publish.

### ربط الحقول بالتصميم (User Data ← المفتاح)
| المفتاح | النوع | اقتراح مكانه في الويدجت |
|---|---|---|
| `icon_image` | media | الصورة الرئيسية / الأيقونة |
| `headline` | string | العنوان |
| `tagline` | string | الوصف |
| `status` | string | سطر فرعي 1 |
| `stat_a` `stat_b` `stat_c` | string | أسطر فرعية / إحصائيات |
| `progress_current` + `progress_max` | number | شريط التقدم (القيمة الحالية والقصوى) |
| `banner_image` | media | خلفية أو بانر إن توفّر في المحرر |

أسماء الخيارات في المحرر قد تختلف قليلاً، والمهم أن تطابق **المفتاح** الذي تكتبه هنا. ويمكنك إضافة أي حقول جديدة من اللوحة (حتى 30).

## 2) الرفع على Render
1. ارفع **كل الملفات** إلى مستودع GitHub خاص (كلها في مجلد واحد بلا مجلدات فرعية).
2. Render ← **New ← Blueprint** ← اختر المستودع (يقرأ `render.yaml` تلقائياً، خطة مجانية).
3. أدخل المتغيرات: `PUBLIC_URL` (رابط خدمتك https)، `DISCORD_APP_ID`، `DISCORD_BOT_TOKEN`، `DISCORD_CLIENT_SECRET`، `ADMIN_PASSWORD` (8 أحرف فأكثر، يفضّل طويلة)، و`MONGODB_URI` (انظر أدناه).
4. بعد النشر افتح `https://خدمتك.onrender.com/admin`.

### التخزين (مهم)
قرص Render المجاني **يُمسح عند كل نشر**. للحفاظ على تعديلاتك استخدم MongoDB Atlas المجاني: أنشئ Cluster ← Database Access (مستخدم) ← Network Access: `0.0.0.0/0` ← انسخ رابط الاتصال إلى `MONGODB_URI`. بدونه ترجع الإعدادات الافتراضية بعد كل نشر.

## 3) أول استخدام
1. ادخل `/admin` بكلمة المرور.
2. اضغط **Link Discord account** ووافق (مرة واحدة فقط).
3. عدّل الحقول ثم **Save & push**.
4. أضف الويدجت لبروفايلك: الإعدادات ← Profiles ← Profile Widgets ← Add Widget (ديسكورد يذكر أن إضافتها تتم من Desktop أو Web).

## 4) التعديل في أي وقت
- من اللوحة: عدّل أي نص أو رقم أو صورة، أضف/احذف حقولاً، أو اضغط Preset جاهزاً (Available / Focus / Away) لتغيير الحالة بلمسة، ويمكنك حفظ Presets جديدة.
- الصور: اختر من المكتبة (الصور PNG في المجلد الرئيسي: شعار L، معيّن، درع، صاعقة، تاج، سداسي، هدف، وبانر داكن) أو ألصق رابط https عاماً (مثل صورة على نطاقك).
- الخدمة المجانية تنام بعد فترة خمول، فأول فتح قد يستغرق نحو دقيقة. لا يؤثر هذا على ظهور الويدجت.

## 5) حل المشاكل
| الرسالة | الحل |
|---|---|
| 403 Application not authorized | قسم Widget غير مفعّل لتطبيقك، أو لم تربط حسابك |
| 401 | رمز البوت خاطئ |
| "does not match existing identity" | غيّرت `IDENTITY_ID`، أعده لقيمته الأولى |
| الصورة لا تظهر | يجب أن تكون https وعامة ويمكن لديسكورد جلبها |
| `Invalid redirect` عند الربط | أضف رابط `/callback` بالضبط في OAuth2 Redirects |

## 6) هل يمكن رفع فيديو؟
لا. الويدجت يقبل **صوراً** (روابط) ونصوصاً وأرقاماً، وليس فيديو. والـ Rich Presence كذلك صور ثابتة فقط. البدائل: GIF كبانر أو صورة شخصية (يتطلب Nitro)، أو صفحة على نطاقك فيها الفيديو وتضع رابطها في Connections.
